## 为什么做这一期

用户在 QiCode 与 pi 中输入相同源码追踪指令，已有日志显示：QiCode 约 207 秒、pi 约 255 秒；QiCode 虽然更快，却压缩了 17 次，部分调用链没有展开，且存在具体结论错误。pi 覆盖更完整，但最终回答约 17900 字符，也有明显阅读负担。

这不是“全面照抄 pi”或“单纯把回答缩短”的问题。下一步应吸收其**主链先行、源码证据完整、结束条件明确**的做法，同时控制读取与输出成本。原始对照的模型、端点、容量和版本未完全对齐，不能作为严格性能排名。证据见 [源码追踪对照](../source-trace-comparison.md)。

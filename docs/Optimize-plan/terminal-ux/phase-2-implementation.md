## 本地验证

- `pnpm typecheck`、`pnpm build` 通过。
- 完整离线测试：59 个测试文件通过，330 项通过、1 项跳过。新增覆盖协议截断/断流、预算暂停、空闲超时、参数验证、换行保持、真实本地工具与恢复证据。
- `pnpm benchmark:offline`：30/30 通过，10 类固定任务各 3 次，使用脚本 Provider 和真实文件/进程工具，独立验收器位于 Agent 工作目录外。JSON 结果保存在本地 `.qicode/benchmarks/`。
- B04 包含真实失败检查、修复后通过；B09 包含外部编辑冲突；B10 在写入后恢复，检查写入不重放。
- 基准 B08 的等待是加速版，不代表超过两分钟的验证；另以 `tsx benchmarks/long-run.ts` 执行 181 秒实际命令作为独立回归。实测 181476 ms、18 次增量更新、退出码 0，通过；没有被旧的两分钟整任务限制终止。临时工作区内保留 `result.json` 与命令日志。

这些数字是确定性执行链路通过率，不是模型自主编码成功率，不证明已达到 pi 的效果。测试未调用模型 API，不产生模型调用费用。

# 第二期验收清单

状态：代码已实现并进行离线、本地集成验证，证据见 [实现记录](../phase-2-implementation.md)。真实模型与 pi 对照尚未执行；下列发布门槛不能由离线脚本测试代替。

## 1. 真实任务集

每个任务必须有独立验收器和固定起点。实现基准时冻结具体仓库、文件与预期，保留一部分验收断言在 Agent 可修改目录之外；不能仅凭如下场景描述就声称基准已建立。

| 场景 | 用户请求类型 | 外部验收重点 |
| --- | --- | --- |
| B01 空配置边界 | 修复已有函数的边界问题 | 原失败用例通过，正常行为不回归 |
| B02 CLI 参数 | 为已有命令增加选项 | 解析、帮助和真实执行一致 |
| B03 多文件联动 | 为配置增加可选字段 | 类型、加载和消费逻辑一致，旧配置兼容 |
| B04 真实失败修复 | 修改后运行检查并解决失败 | 至少一轮实际失败后再修改并通过 |
| B05 大仓库定位 | 从错误定位调用链并修复 | 修改正确目标，不扫描依赖/无关目录失控 |
| B06 读取分页 | 在长文件尾部修正问题 | 不因只读前半文件而漏改或臆测 |
| B07 格式兼容 | 修改 CRLF/BOM 中文文件 | 改动正确且原格式保留 |
| B08 长验证 | 修改后运行超过两分钟的检查 | 正常执行至结束，有增量输出与退出证据 |
| B09 外部冲突 | 编辑期间文件被外部更新 | 冲突不覆盖，重新读取并合理恢复或阻塞 |
| B10 崩溃续做 | 修改后退出，再继续验证交付 | 工作现场恢复，无副作用重复执行 |

每项 3 次，共 30 次；B09 成功指正确处理冲突，不要求覆盖受保护内容。B10 的预设重启步骤属于场景控制，不算模型需要人工指点。

## 3. 确定性故障与运行时验收

- [ ] 两种协议均覆盖分片工具调用、多工具、坏 JSON、错类型、截断但 JSON 可解析、无终止断流；不执行危险的残缺输入。
- [ ] 工具 ID 配对、同一调用不重复执行；权限拒绝、取消、Hook 拒绝、未知工具均形成合法历史。
- [ ] 验证失败后读取错误并修复；达到 3 轮修复或总预算时明确结束，不无限回环。
- [ ] 最新修改使旧验证证据失效；预先存在失败与新增失败可区分；不得删除验收器或弱化测试掩盖问题。
- [ ] 命令取消/超时后保留部分日志；stdout/stderr 有界展示、完整内容可访问；输出配额耗尽明确标记。
- [ ] 模型、压缩、工具和权限等待都可取消；授权等待不吞有效任务预算。
- [ ] 429/临时网络失败有界重试，401/参数错误不空转；写入已生效后的网络失败不重跑整任务。
- [ ] intent 无 outcome 的崩溃命令标未知；再次执行前核对，不把缺结果当成没执行。
- [ ] 旧文本会话仍可恢复且标注信息有限；新会话包含工具、验证和停止状态，损坏尾部与存储故障可见。
- [ ] 原有读后写、文件版本、路径沙箱、危险命令与检查点保护保持有效；用户已有改动不会被自动覆盖/回滚。

确定性测试中的假完成、副作用重复执行、覆盖并发修改和凭据泄露必须为零。

## 4. 平台与证据

优先 Windows Terminal + PowerShell 7、VS Code 集成终端；核对真实命令后端，不能仅记录启动 QiCode 的 Shell。补测 Linux/macOS 受支持 Shell，不把未测试平台写成已兼容。

每次运行保存：应用提交、任务起点、模型与参数、执行预算、权限设置、终端/系统版本、任务输入、工具事件、最终 diff、检查日志、外部验收结果。日志不保存认证头、密钥或完整环境变量，私密项目证据仅本地保留。

离线验证用假 Provider、临时目录和本地脚本；真实模型任务另行执行，既有单元测试通过不代表达到能干活目标。

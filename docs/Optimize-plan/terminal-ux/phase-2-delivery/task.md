## 控制单人投入

一次只推进一个可验收的任务；每个任务附真实复现、对应修复和必要的回归证据。提示词行为要用实际模型基准验证，确定性状态与协议用本地假 Provider 测试，不能相互替代。

本规划不估造人日。T01 完成后依据失败分布安排工期：协议不通先协议、Windows 命令失败先 Shell、已能修改却测试不闭环则先验证。顺序可以据证据调整，发布门槛不降低。

每个实现批次运行相应测试；整期结束必须运行 `pnpm typecheck`、`pnpm test`、`pnpm build`。真实模型基准单独运行并明确费用/网络前提，不把它接入默认离线测试。

# 终端外观整理

2026-11-07。针对“终端界面美观一点”，在现有 Ink 组件上调整视觉，不更换渲染框架，不改按键行为和模型调用。

- 保留三行 ASCII 猫咪和紫色标识；模型用青色，版本与路径弱化，长路径截断，不挤压 Logo。
- 标题与输入区使用细分隔线。紧凑布局、弹窗与极窄输入区减少装饰，保留空间给输入。
- 空白会话显示具体任务提示与常用入口；输入为空时显示占位提示，不写入实际草稿。
- 状态栏缩短用量数字，右侧独立保留取消/退出入口；小窗口隐藏累计用量、改用上下文比例，减少拥挤。
- 回复使用紫色身份、清晰标题和段落留白；代码用青色，工具输出保持低调。普通通知为灰色，警告黄色，错误红色。
- 选择器统一标题与焦点颜色；启动选择器使用中文提示。运行指示沿用已有动画，刷新间隔从 80 ms 调到 120 ms。

颜色使用语义化 ANSI 调色板，沿用用户终端的字体、背景与颜色方案，不强行覆盖背景。高对比度偏好继续生效于聊天工具输出和状态栏。

检查：类型检查通过；相关 UI 布局、按键和弹窗检查共 29 项通过（初次 28 项通过，极窄布局问题修复后单独复验剩余 1 项）。用离线渲染检查 80/60/40 列头部与状态栏，没有调用模型 API、没有运行全量测试。真实终端字体、颜色和输入法效果仍以用户实际终端为准。

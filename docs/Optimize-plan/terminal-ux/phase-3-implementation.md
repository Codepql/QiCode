# 第三期：会话延续与长期使用

日期：2026-11-06。沿用三期总纲 P3-01–P3-07，用户已确认进入实现。保留原来的 ASCII 猫咪、Header 和 Ink 布局，不增加依赖。

## 设计与实现

采用现有 CommandRegistry + 共用搜索/预览弹窗，复用一期焦点路由、第二期结构化会话和既有后台任务、团队、文件历史后端。列表有可见窗口，详情单独滚动；弹窗消费按键，关闭后保留输入草稿。

| 入口 | 行为 |
| --- | --- |
| `/resume`、Alt+S | 按标题、ID、摘要、项目搜索历史会话，展示时间和实际消息数，Tab 预览、Enter 恢复；损坏记录给出警告，完全不可恢复时保留当前会话 |
| `/resume latest` | 恢复最近的其他会话 |
| `/rename 标题`、`/new` | 命名当前会话、新建会话；切换前保存草稿，未发送草稿也可在会话列表找到 |
| `/model`、Alt+M | 选择已配置 Provider/model；展示协议、thinking、容量与输出能力，不展示密钥；运行中登记，结束后切换；`/model cancel` 撤销登记 |
| 模型兼容检查 | 有未配对工具调用时阻止切换；签名思考块须确认转换，只删除隐藏思考块，保留可见对话与工具结果；初始化失败保持原配置，首次请求失败且工具未开始执行时回到原模型 |
| 状态栏 | 当前消息、流式正文、提示词和工具 schema 的上下文估算与容量；独立显示会话进程内累计输入/输出用量；容量未配置时显示未知，运行时仍使用第二期保守预算 |
| `/compact` | 手动压缩可以取消；显示压缩结果，失败恢复原消息，不把累计 tokens 当作上下文占用 |
| `/settings`、Alt+B | 保存紧凑布局、工具结果预览、高对比度、下次启动安全权限与首选模型；可恢复默认。来源为项目内 `.qicode/ui.json`，不改 Provider 配置，不自动保存全放行权限 |
| `/hotkeys` | 展示有效快捷键；`/settings bind 动作 alt+键` 调整会话、模型、任务、设置入口，重复或保留按键拒绝保存 |
| `/files`、`@路径` 后 Tab | 搜索工作区普通文件、忽略依赖和构建目录；预览前限制工作区边界，拒绝二进制；中文/空格路径使用引号补全。确认后只引用路径和大小，由 Agent 按需分页读取正文 |
| `/files remove 序号` | 移除已选文件；最多 20 个文件，列表最多展示 200 项 |
| `/tasks`、Alt+T | 主任务、后台任务和团队成员按需查看；Tab/Enter 查看滚动详情、结果和命令日志路径；Ctrl+X 仅取消当前所选对象，不调用 cancelAll |
| `/rewind`、`/rewind 序号` | 先选择并预览时间、文件范围与冲突，再明确选择“只恢复文件”或“文件与对话”；发现冲突不提供写入确认；执行时沿用锁和版本校验，回退消息持久化 |

会话标题与草稿独立放在 `.qicode/session-meta/`，兼容已有 JSONL。输入草稿延迟 500 ms 保存，明确切换时同步保存；进程突然终止仍可能丢失最后 500 ms 输入。草稿写入失败显示通知。

按用户最新要求，小改动不逐次运行测试；功能集中实现后只运行相关的本地测试与工程检查，不重复跑全量套件、不调用真实模型 API。

## 当前限制

- 这是第三期功能实现，不是生产可靠性或与 pi 同条件成功率的证明；第二期真实模型对照仍未执行。
- 仅选择现有 Provider 配置，不在线拉取或猜测模型列表；初始化不做收费 API 探测。模型切换后工具已开始执行时，不为回退配置而重放任务。
- 上下文数字为估算，不是服务端精确计数；会话累计用量只涵盖当前进程观测到的请求，恢复旧会话后未知用量显示空值。
- 文件选择忽略公共依赖/构建目录，尚未完整解释所有 `.gitignore` 语义；预览最多 4096 字节/20 行，不代表完整读取或内容信任。
- 任务面板的主任务结果有界保存最近 24000 字符；完整命令日志仍在磁盘。后台任务和团队的独立执行目录只有底层返回后才能核对，面板显示启动工作区及可确认的分支，不猜测子任务分支。
- 设置只提供现有配色的高对比度版本、中文提示与入口快捷键调整；不包含完整主题引擎、全界面多语言、任意编辑器按键重绑定。
- 检查点只覆盖已追踪编辑，不能撤销任意 Shell、外部服务或部署副作用。未增加会话树或历史分叉。
- Windows Terminal、VS Code 真终端输入法与连续 resize 的人工验收仍待执行，组件测试不能代替。

本轮未提交、推送或发布版本。

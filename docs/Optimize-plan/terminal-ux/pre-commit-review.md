## Standards / 实现审查

审查发现两个新增问题及一个相关基线问题，均已修复：

1. 只读 Git 快速放行没有识别 PowerShell 智能引号及 POSIX 转义，可能把看似位置参数的文本变成 `--output` 写入选项。现拒绝这两类语法进入快速通道，保留普通授权，并覆盖回归用例。
2. 同一版本连续运行多个失败检查，被误算成多轮修复。现同一 revision 的多个失败只计一轮，让模型有机会处理一组失败。
3. Anthropic 后续 output-only usage 会清掉此前输入计数。现只在收到输入或有效缓存输入计数时更新上下文锚点，输出事件不覆盖它。该问题原已存在，本次一并修复。

共 3 项修复；最高风险是未经授权写入的 Git 快速通道绕过，已增加边界检查。

## Spec / 需求符合审查

对照三期总纲 P3-01/P3-07、第二期执行闭环及授权/压缩修订，发现两项问题并修复：

1. 初始会话清空草稿后可能跳过保存，恢复时会带回已经提交的文本。现接受输入时同步清理持久化草稿，编辑到空值也会清除既有存档；保存失败保留原输入。
2. v2 恢复时重复前置 durable/MCP 上下文，会增大历史并移动检查点消息索引。现识别合法结构消息，将已知上下文原位刷新；新增上下文追加在尾部，已有历史索引保持不变。恢复提醒也原位刷新，避免每次恢复继续增长。旧纯文本会话保留兼容路径。

共 2 项修复；主要影响为草稿重复提交和恢复后上下文/检查点偏移，已有回归覆盖。
